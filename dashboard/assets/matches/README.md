# Match Photos

Drop match profile photos here for the phone top-half.

## File naming

Use the lowercase slug of the display name:

- `grusha.jpg`
- `roxana.jpg`
- `rachel.jpg`
- `winnie.jpg`
- `annie.jpg`

Supported extensions: `.jpg`, `.jpeg`, `.png`, `.webp`

## Recommended resolution

Use portrait images at `1080 x 1350` (4:5).

This gives enough detail for the rounded-corner crop while keeping files manageable.
